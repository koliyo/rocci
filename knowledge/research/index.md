# Research

* [Implemented method:role handlers compared with the Datastar ecosystem](method-role-handlers-datastar-ecosystem.md) - Post-landing: Rocci's closed `@method:role(path)` matrix is shipped and unique as language syntax. Datastar SDKs and app frameworks (Stario, Lambda Combine, Dstar, official Go/Python/…) share CQRS and HTML-patch architecture but leave response roles to handler bodies. On the right track for hypermedia DX; hard ceiling on Datastar's full SSE/SDK surface. Exploratory.
* [Inline interpolation in Rocdown Markdown](rocdown-inline-interpolation.md) - Settled Markdown hole is `@{expr}` (prefix around Rocci `{expr}`). `{@expr}` and `{{expr}}` stay rejected alternatives. Implementation: [Rocdown `@{expr}`](../plans/rocdown-inline-interpolation.md). Follow-on: [`@{expr}` follow-ons after v1](../plans/rocdown-inline-interpolation-follow-ons.md). Not shipped. Exploratory.
* [rocci.dev documentation should follow the stack, not a documentation academy](rocci-dev-docs-stack-ia.md) - The shipped `/docs/` corpus is accurate but organized as a Diátaxis curriculum with academy chrome and a Rocci-only learning path. Recommend stack-layer nav (templates, applications, `/docs/rocdown/`), a clean URL cut with no aliases, and Diátaxis as an authoring lens only. Implementation: [stack-first docs](../plans/rocci-dev-docs-stack-ia.md). Exploratory.
* [basic-webserver 0.16 SSE and HTTP limits for Rocci live streams](basic-webserver-sse-http.md) - Silent `Sse.Wait` hits the 30s response idle timeout; hyper Body-stream logs omit the inner error; browsers on plaintext `rocci run` stay HTTP/1.1 (Datastar does not require HTTP/2). Rocci workarounds: live keepalives and empty SSE commands. Does not fork the platform. Related: [Datastar SSE vs fan-out](datastar-cqrs-action-responses.md).
* [Bound Rocci handlers to server-rendered UI](action-handler-syntax.md) - Historical research that revised the four-noun handler cutover: GET HTML fragments are the missing UI read, negotiated command JSON is a partial API contract that should leave the high-level surface, and patch-signals belongs in low-level Roc transport helpers rather than declaration syntax. Its `@patch` versus `@fragment` gate is resolved by the landed [verb-first follow-up](verb-first-handler-declarations.md). Historical plan: [semantic handlers](../plans/action-handler-syntax.md).
* [Verb-first handler declarations for Rocci's bounded UI surface](verb-first-handler-declarations.md) - Evidence for mandatory `@method:role` headers: `@get:view`, `@get:fragment`, mutation `:fragment` / `:command`, and path-addressed `@get:live`. Aligns server routes with backend and Datastar conventions while rejecting bare defaults, API/media/event permutations, and high-level patch-signals. Implementation: [verb-first handlers](../plans/verb-first-handler-declarations.md). Historical research; the language is implemented on `verb-first-handler-declarations`.
* [Path-addressed live streams for multi-page Rocci applications](path-addressed-live-streams.md) - A path alone only renames the singleton; first-class multi-page support requires plural `@get:live(path)` routes, app-level binding of primary and sibling streams, collision validation, and deterministic subscription injection. Recommends one page/coherence stream that may patch several IDs, not one connection per component. Implementation: [path-addressed live routes](../plans/path-addressed-live-streams.md). Historical research; the language is implemented with the verb-first cutover.
* [Findings after migrating operator scripts to Python and uv](python-uv-ops-pipeline.md) - POSIX remains PID 1, image Roc install, and ProxyCommand. Later Roc port should reuse `rocci-ops` names; uv stays the operator runtime until `basic-cli` covers CI, laptops, and origin. Implementation plan: [Python uv pipeline](../plans/python-uv-ops-pipeline.md). Exploratory.
* [Datastar SSE is a per-request transport; generated apps do not fan out](datastar-cqrs-action-responses.md) - One-shot POST fragments update only the acting tab. Fan-out is Tao CQRS. Historical record of generated `@live` plus empty-SSE Datastar commands with ordinary-client JSON. The landed command contract is empty SSE for Datastar and 204 for ordinary callers; live routes are now path-addressed `@get:live`. Platform idle-timeout and HTTP/1.1 limits: [basic-webserver SSE and HTTP](basic-webserver-sse-http.md). Historical plan: [generated CQRS and `@live`](../plans/datastar-cqrs-action-responses.md).
* [Snapshot eval must not compile service-only `@roc`](island-snapshot-roc-reachability.md) - SQLite never runs on the CDN. Live pages compile twice (`basic-cli` snapshot HTML vs `basic-webserver` handlers). Roc typechecks unused helpers, so one `pf.Sqlite` is two APIs. Platform unification and Roc skipping unused bindings are not available; Rocci ships a lowering reachability subset. Implementation plan: [snapshot reachability](../plans/island-snapshot-roc-reachability.md). Exploratory.
* [Ungrammar as AST spec for Rocci and Rocdown](ungram-ast.md) - Exploratory recommendation: ungrammar as the tree spec for both languages; generate owned AST structs; do not generate scanners. Implementation plan: [ungram AST codegen](../plans/ungram-ast.md). Not shipped.
* [Optional request argument on Rocci service handlers](optional-handler-request.md) - Shipped: one-parameter `@on` lists inject unused `_request` at lowering so dispatch stays `handler!(context, request)`. Follow-ons (dispatch arity, request as a handler-input field) are exploratory and not shipped.
* [Efficient publishing of Rocdown sites and Rocci apps](efficient-publishing.md) - Build-once artifact model: static `dist/` needs only a file server; keep native apply because basic-cli/webserver have no wasm32; Roc `--target` can emit Linux musl from macOS for process binaries. Implementation plan: [efficient publishing](../plans/efficient-publishing.md). Exploratory; not approved.
* [Publishing rocci.dev with Cloudflare, a small origin, and CI](rocci-dev-publish.md) - Cloudflare as the CDN (not Pages); Tunnel plus Universal SSL for `.dev` HSTS; Hetzner Cost-Optimized x86 in Falkenstein/Nuremberg (OVH VPS-1 Germany as fallback) runs existing hybrid Compose; GitHub Actions packages `site/` until Tangled owns Linux CI. Implementation plan: [deploy rocci.dev](../plans/rocci-dev-publish.md). Exploratory; not approved.
* [Hybrid Rocdown islands for CDN-static sites](hybrid-rocdown-islands.md) - Exploratory research: CDN-static HTML with dynamic Rocci components backed by a rocci/rocdown HTTP service. Implementation plan: [hybrid Rocdown islands](../plans/hybrid-rocdown-islands.md) (rebase onto main's `:name` forest required). Not shipped.
* [Generalized Rocdown block model](generalized-rocdown-block-model.md) - Article blocks as `:name[params]` with `{{ }}` bodies. Source spelling shipped; original record still exploratory on leftover open questions. Follow-on: [custom block schemas and renderers](rocdown-block-renderers.md).
* [Custom Rocdown block schemas and renderers](rocdown-block-renderers.md) - Design research for `:kind` as a Rocci function interface, constrained children, site-selected painters, debug fallback. Worked `:callout` sketches and why named Roc structs are not the v1 schema source. Overlay is in the crate; leftover `@block` / heading Prose are not. Plan: [custom block schemas and renderers](../plans/rocdown-block-renderers.md). Post-landing comparison: [landed renderers vs related systems](rocdown-block-renderers-comparison.md).
* [Landed Rocdown block renderers compared with related systems](rocdown-block-renderers-comparison.md) - Exploratory scores of the shipped KindSpec plus theme pack against Markdoc, MDX, Nuxt, Gutenberg, Typst, and related systems. Follow-on: authoring DX, authorable surface, expressability ceiling, and stack-consistency fractures. Remaining gaps: custom-kind child policy, typed lists into parent painters, `@block`, heading Prose.
* [Desktop host chrome versus Rocci inspector UI](desktop-host-chrome-and-inspector-ui.md) - Split wry overlay chrome (HTML/CSS/JS) from preview-origin Rocci panels for compiler metrics and similar richer UI.
* [Extended preview-window inspector](preview-inspector.md) - Dock/tabs/console shells landed; Source still does not scroll and overlay dock chrome covers tabs. Remaining work: [investigate and repair the preview inspector](../plans/preview-inspector-repair.md). Exploratory.
* [Preview inspector console scope](inspector-console-scope.md) - Console stays a host runtime stream (CLI, watch, Roc stderr). Do not add logging from Rocci `@component` functions. Implementation: [runtime console without a component log API](../plans/inspector-console-scope.md). Exploratory.
* [Handler logging into the Rocci runtime console](handler-runtime-logging.md) - `@on` / `@init` can already reach Console and CLI via `pf.Stderr.line!` (`source: runtime`). Prefer a stderr prefix plus optional `log!` helper for `source: app`; reject markup `@log` and HTTP ingest as the primary path. Exploratory; no plan started.
* [Branding and community foundation](branding-community-foundation.md) - Exploratory masterbrand, naming, SEO, visual-identity, and public-preview community research.
* [Repository hosting for Rocci's distributed governance](repository-hosting-and-distributed-governance.md) - GitHub and Tangled comparison for public launch, contributor workflow, infrastructure ownership, and future shared authority.
* [Tangled as canonical host with a GitHub macOS CI mirror](tangled-hosting.md) - Inverse topology for a near-term public open-source clone: Tangled owns git, issues, PRs, and Linux CI; GitHub remains a SHA-faithful mirror for `macos-latest` Actions. No shipped orgs; grouping is sibling repos under one handle. Implementation plan: [Tangled hosting](../plans/tangled-hosting.md). Exploratory; not approved.

Follow-on: [deferred compile/render follow-ons](../plans/okf-compile-render-follow-ons.md). Exploratory; not shipped.
