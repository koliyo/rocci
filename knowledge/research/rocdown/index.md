Format, blocks, interpolation, islands, and the app-docs compiler.

* [Inline interpolation in Rocdown Markdown](rocdown-inline-interpolation.md) - Settled Markdown hole is `@{expr}` (prefix around Rocci `{expr}`). `{@expr}` and `{{expr}}` stay rejected alternatives. Implementation: [Rocdown `@{expr}`](/plans/rocdown/rocdown-inline-interpolation.md). Follow-on: [`@{expr}` follow-ons after v1](/plans/rocdown/rocdown-inline-interpolation-follow-ons.md). Not shipped. Exploratory.
* [Generalized Rocdown block model](generalized-rocdown-block-model.md) - Article blocks as `:name[params]` with `{{ }}` bodies. Source spelling shipped; original record still exploratory on leftover open questions. Follow-on: [custom block schemas and renderers](rocdown-block-renderers.md).
* [Snapshot eval must not compile service-only `@roc`](island-snapshot-roc-reachability.md) - SQLite never runs on the CDN. Live pages compile twice (`basic-cli` snapshot HTML vs `basic-webserver` handlers). Roc typechecks unused helpers, so one `pf.Sqlite` is two APIs. Platform unification and Roc skipping unused bindings are not available; Rocci ships a lowering reachability subset. Implementation plan: [snapshot reachability](/plans/rocdown/island-snapshot-roc-reachability.md). Exploratory.
* [Hybrid island hydration versus SSR island frameworks](hybrid-island-hydration.md) - `static` / `hydrate` / `live` is build-time Html splice plus an optional Datastar service, not React/Astro client hydration. v1 shipped and experimental; `@island` JS is not. Knowledge status records still describe the pre-ship gate. Exploratory.
* [Hybrid Rocdown islands for CDN-static sites](hybrid-rocdown-islands.md) - Design-era research for CDN HTML plus an island HTTP service. v1 of that shape shipped on `main` (see [hydration comparison](hybrid-island-hydration.md)). Implementation plan: [hybrid Rocdown islands](/plans/rocdown/hybrid-rocdown-islands.md). Historical “not shipped” wording in the body is stale.
* [Efficient publishing of Rocdown sites and Rocci apps](efficient-publishing.md) - Build-once artifact model: static `dist/` needs only a file server; keep native apply because basic-cli/webserver have no wasm32; Roc `--target` can emit Linux musl from macOS for process binaries. WASI HTTP gap inventory: [basic-webserver WASI](/research/rocci/basic-webserver-wasi.md). Implementation plan: [efficient publishing](/plans/rocdown/efficient-publishing.md). Exploratory; not approved.
* [Custom Rocdown block schemas and renderers](rocdown-block-renderers.md) - Design research for `:kind` as a Rocci function interface, constrained children, site-selected painters, debug fallback. Plan: [custom block schemas and renderers](/plans/rocdown/rocdown-block-renderers.md). Post-landing comparison: [landed renderers vs related systems](rocdown-block-renderers-comparison.md).
