# Rocci

Templates, handlers, runtime, desktop inspector, component generation, and falling-block.

* [Rocci application structure and run entry](application-structure-and-entry.md) - A directory is a bag of modules; `rocci run <dir>` still needs `main.roc`. At most one process `@init` (or none); optional `rocci.toml` entry; do not reuse `apps.toml`. Implementation: [directory-as-app entry](/plans/rocci/application-structure-and-entry.md). Exploratory.
* [Generated live SSE is a timer poll, not write-triggered push](live-sse-is-timer-poll.md) - 100ms is the per-connection render poll, not a required keepalive. The 30s idle timeout is a hung-response detector (SSE silence is legal); keepalive every ~15s. A second-resolution "ago" in live HTML emits a real patch every second; the demo now buckets `< 60s` as "just now". Write-triggered wake is not in basic-webserver 0.16. Exploratory.
* [Untagged style siblings on Datastar patch-elements](sse-patch-style-targets.md) - 2026-08-30 incident: `embed_css` puts a sibling `<style>` on fragment patches; Datastar logs PatchElementsNoTargetsFound while the id roots still morph. Fix strips style in `Datastar.patch_elements`. Recommend wire-format target tests, not browser e2e. Pair: [SSE patch-target tests](/plans/rocci/sse-patch-target-tests.md). Exploratory.
* [A Mojo-based Rocci alternative after Mojo 1.0](mojo-based-rocci.md) - Exploratory counterfactual: Mojo 1.0 is indent-based, comptime-parameterized, and Python-interop stable, but has no custom decorators, no match/unions, and unfinished async. Do not use indent as an HTML or Rocdown closer; honest fits are a paren Html library, a Python+Datastar host with Mojo kernels, or compute islands—not a retargeted `.rocci` grammar. Not a plan.
* [Datastar Rocket and Rocci-native islands (current)](datastar-rocket.md) - 2026-08-28 restatement of the archived Rocket report: ownership and no-bundle still hold; syntax, `rocci-http`, CSS artifacts, site CSP, and Snake `snake-input.js` have moved. Custom-element morph identity is still unproven. Pair: [`@island` blockers](client-behavior-islands.md). Exploratory.
* [Client-behavior `@island` design blockers](client-behavior-islands.md) - Reserved `@island` is designed (light-DOM custom element + `*.client.js`), not approved, not implemented. Do not write a grammar plan until a no-syntax morph spike and a human accept/reject of the exploratory decision. Pair: [hydration vs SSR](/research/rocdown/hybrid-island-hydration.md). Current Rocket map: [datastar-rocket](datastar-rocket.md). Exploratory.
* [Rocci @test syntax lowered to Roc expect](rocci-test-syntax.md) - Root `@test name = boolExpr` plus optional `{fixture: name}`; `expect` after `Type := [].{ }` with type-module aliases; `rocci test` via `roc test {Type}.roc`. Implementation: [implement @test and rocci test](/plans/rocci/rocci-test-syntax.md). Exploratory; Phases 0–7 on `rocci-test-syntax`; not logged complete until CI and Knowledge succeed.
* [Roc nightly 2026-08-23 record defaults versus Rocci ??](roc-nightly-record-defaults.md) - `fb208ba` typechecks `{ name : Str ?? "Roc" }` and `timeout_ms ?: U64`. Pattern `|{ name ?? "Roc" }|`, positional defaults, and omitting unused closed record fields still fail. Implementation: [pin Roc and emit type-position defaults](/plans/rocci/roc-nightly-defaults.md). Exploratory.
* [Implemented method:role handlers compared with the Datastar ecosystem](method-role-handlers-datastar-ecosystem.md) - Post-landing: Rocci's closed `@method:role(path)` matrix is shipped and unique as language syntax. Datastar SDKs and app frameworks share CQRS and HTML-patch architecture but leave response roles to handler bodies. On the right track for hypermedia DX; hard ceiling on Datastar's full SSE/SDK surface. Exploratory.
* [Verb-first handler declarations for Rocci's bounded UI surface](verb-first-handler-declarations.md) - Evidence for mandatory `@method:role` headers: `@get:view`, `@get:fragment`, mutation `:fragment` / `:command`, and path-addressed `@get:live`. Aligns server routes with backend and Datastar conventions while rejecting bare defaults, API/media/event permutations, and high-level patch-signals. Implementation: [verb-first handlers](/plans/rocci/verb-first-handler-declarations.md). Historical research; the language is implemented on `verb-first-handler-declarations`.
* [Path-addressed live streams for multi-page Rocci applications](path-addressed-live-streams.md) - A path alone only renames the singleton; first-class multi-page support requires plural `@get:live(path)` routes, app-level binding of primary and sibling streams, collision validation, and deterministic subscription injection. Recommends one page/coherence stream that may patch several IDs, not one connection per component. Implementation: [path-addressed live routes](/plans/rocci/path-addressed-live-streams.md). Historical research; the language is implemented with the verb-first cutover.
* [Bound Rocci handlers to server-rendered UI](action-handler-syntax.md) - Historical research that revised the four-noun handler cutover: GET HTML fragments are the missing UI read, negotiated command JSON is a partial API contract that should leave the high-level surface, and patch-signals belongs in low-level Roc transport helpers rather than declaration syntax. Its `@patch` versus `@fragment` gate is resolved by the landed [verb-first follow-up](verb-first-handler-declarations.md). Historical plan: [semantic handlers](/plans/rocci/action-handler-syntax.md).
* [Datastar SSE is a per-request transport; generated apps do not fan out](datastar-cqrs-action-responses.md) - One-shot POST fragments update only the acting tab. Fan-out is Tao CQRS. Historical record of generated `@live` plus empty-SSE Datastar commands with ordinary-client JSON. The landed command contract is empty SSE for Datastar and 204 for ordinary callers; live routes are now path-addressed `@get:live`. Platform idle-timeout and HTTP/1.1 limits: [basic-webserver SSE and HTTP](basic-webserver-sse-http.md). Historical plan: [generated CQRS and `@live`](/plans/rocci/datastar-cqrs-action-responses.md).
* [basic-webserver 0.16 SSE and HTTP limits for Rocci live streams](basic-webserver-sse-http.md) - Silent `Sse.Wait` hits the 30s response idle timeout; that default is a hung-response detector, not an SSE liveness interval. Hyper Body-stream logs omit the inner error; browsers on plaintext `rocci run` stay HTTP/1.1. Rocci workarounds: 15s live keepalives and empty SSE commands. Does not fork the platform. Related: [timer poll vs keepalive](live-sse-is-timer-poll.md), [Datastar SSE vs fan-out](datastar-cqrs-action-responses.md).
* [Gaps for running basic-webserver as a WASI HTTP module](basic-webserver-wasi.md) - 0.16 is a native Tokio/Hyper process with no `wasm32` target. Portable WASI HTTP inverts listen into async `handle`. The Roc handler call is blocking C-ABI (CPU occupancy); generated SSE `Wait` already lives in the host after Roc returns. Nested hosted I/O inside `respond!` is the real stall. Experimental embedder ships hello-web, SSE Wait overlap, one preopen, and sync sqlite (serializes). Option 1 shipped: `--http-module` is a WASI 0.3 component `wasmtime serve -Sp3 -Scli` accepts. App-link Phase 0: both nightlies emit `roc_*_for_host` in `roc_app_llvm_wasm32_speed.o`; `--no-link` is absent; Roc's linked `.wasm` strips those names. Remaining: object link and sqlite-in-component so Counter is the served app. Implementation: [WASI HTTP adapter](/plans/rocci/basic-webserver-wasi.md), [0.3 component](/plans/rocci/wasi-http-03-component.md), [app link](/plans/rocci/wasi-http-03-app.md). Exploratory.
* [Ungrammar as AST spec for Rocci and Rocdown](ungram-ast.md) - Exploratory recommendation: ungrammar as the tree spec for both languages; generate owned AST structs; do not generate scanners. Implementation plan: [ungram AST codegen](/plans/rocci/ungram-ast.md). Not shipped.
* [Rocci components in the generation pipeline](rocci-components-in-generation.md) - Evidence for moving demonstrated HTML chrome into Rocci, native subprocess versus Wasmtime hosts, two-tier renderer caching, and glue as a later native host.

* [Preview inspector console scope](inspector-console-scope.md) - Console stays a host runtime stream (CLI, watch, Roc stderr). Do not add logging from Rocci `@component` functions. Implementation: [runtime console without a component log API](/plans/rocci/inspector-console-scope.md). Exploratory.
* [Handler logging into the Rocci runtime console](handler-runtime-logging.md) - `@on` / `@init` can already reach Console and CLI via `pf.Stderr.line!` (`source: runtime`). Prefer a stderr prefix plus optional `log!` helper for `source: app`; reject markup `@log` and HTTP ingest as the primary path. Exploratory; no plan started.
* [Optional request argument on Rocci service handlers](optional-handler-request.md) - Shipped: one-parameter `@on` lists inject unused `_request` at lowering so dispatch stays `handler!(context, request)`. Follow-ons (dispatch arity, request as a handler-input field) are exploratory and not shipped.

* [Method-role handlers as a pure Roc library or platform](method-role-handlers-as-roc-library.md) - Counterfactual: encode the closed matrix as Roc role constructors on basic-webserver (a custom platform buys little DX). Exploratory; not a cutover plan.
