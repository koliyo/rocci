# Rocdown

Format, blocks, interpolation, islands, and the app-docs compiler.

* [Rocdown Markdown `@{expr}` interpolation](rocdown-inline-interpolation.md) - Mid-sentence Roc `Str` holes as `@{expr}`: Comrak Text split, source-aware `\@{` escape, hydrate promotion, `Html.text` lowering. Not `{@expr}`, `{{expr}}`, or a Rust evaluator. Research: [inline interpolation](/research/rocdown/rocdown-inline-interpolation.md). Follow-on: [`@{expr}` follow-ons after v1](rocdown-inline-interpolation-follow-ons.md). Exploratory; not marked stable.
* [Rocdown `@{expr}` follow-ons after v1](rocdown-inline-interpolation-follow-ons.md) - After v1 on `rocdown-inline-interpolation`: fail closed on the Rust article path, align hydrate matrices, lock splitter/placement tests, and stop LSP go-to at an unbound hole. Not heading or URL interpolation. Parent: [`@{expr}` interpolation](rocdown-inline-interpolation.md). Exploratory.
* [Rocdown product-boundary refactor](rocdown-boundary-refactor.md) - Phased consolidation of the Rocdown format and static generator, removal from base Rocci, Rocs retirement, and OKF separation.
* [Custom Rocdown block schemas and renderers](rocdown-block-renderers.md) - Schema/renderer split for `:kind` blocks. Phases 1–7 are in the crate (child policy, pack overlay, `[blocks]`, debug painter, custom kinds from headers, generated dispatcher); Phase 2 typed lists still flatten to Html before the parent painter. Phase 8 `@block` and Phase 9 heading Prose are not shipped. Post-landing comparison: [landed renderers vs related systems](/research/rocdown/rocdown-block-renderers-comparison.md).
* [Generalized Rocdown block model](generalized-rocdown-block-model.md) - Phases 1–7 shipped on `main` (`BlockCall`, `:name[params]`, closed registry, per-kind Rocci renderers, typed props). Phases 8–9 (`@use`, editor completeness) remain exploratory. Follow-on: [custom block schemas and renderers](rocdown-block-renderers.md).
* [Hybrid Rocdown islands for CDN-static sites](hybrid-rocdown-islands.md) - Phases 1–10 shipped on `main` (BlockCall rebase, dual apply, preview-as-site, one-origin islands). Follow-ons exploratory.
* [Hybrid island hosting follow-ons](hybrid-island-hosting-follow-ons.md) - After the local Docker same-origin demo: WebKit-free `--no-window` binaries, a precompiled island binary without `roc` at runtime, and cross-origin CORS plus cookies. Static-first artifact Docker is [efficient publishing](efficient-publishing.md). Exploratory; no phase started.
* [Snapshot eval must not compile service-only `@roc`](island-snapshot-roc-reachability.md) - Live pages compile twice (`basic-cli` splice vs `basic-webserver` handlers). Omit `@roc` helpers the snapshot does not use so authors keep one `@roc` block. Exploratory; Phases 1–4 implemented in this revision, not CI-complete. Research: [snapshot eval two platforms](/research/rocdown/island-snapshot-roc-reachability.md).
* [Documentation generator for Rocci applications](rocci-app-docs.md) - Own app-docs staging in `crates/rocci-docs` (`rocci-docs` binary). Colocated Rocdown plus a full highlighted source tree mounts on rocci.dev at `/examples/<id>/`; only catalog `live` apps get separate hostnames. Skip Rocdown examples. Published source follows `@method:role` routes. Exploratory; Phases 0–6 implemented on `rocci-app-docs`, not CI-complete. Live hostname serving, Launch, and catalog `site` inclusion are [publish example origins](/plans/site/publish-example-origins.md). Historical predecessor: [semantic handlers](/plans/rocci/action-handler-syntax.md).
* [Comprehensive Rocci documentation for rocci.dev](comprehensive-rocci-documentation.md) - Historical fill of a Rocci-first Rocdown-authored manual (Phases 0–6 on `comprehensive-rocci-documentation`). Visible Diátaxis curriculum, academy chrome, Rocdown-out-of-scope, and the URL-alias rule are superseded by [stack-first docs](rocci-dev-docs-stack-ia.md). Other quality rules remain. Phase 7 first-use sessions are not a gate for the IA rewrite.
* [Efficient publishing workflow for pre-built Rocdown sites and Rocci apps](efficient-publishing.md) - Build once on a toolchain host; local Docker serves artifacts. Keep `rocdown build --host native|wasm`. Phases 1–5 implemented on this branch (static Caddy, package/serve, musl `--target`, slim hybrid and app images). Phase 6 is a no-go: musl remains the portable process story; Wasm remains apply. Research: [efficient publishing](/research/rocdown/efficient-publishing.md). Exploratory; not CI-complete.
* [Make directory plus index the Rocdown site section](docs-directory-semantics.md) - Phases 0–6 implemented on `docs-directory-semantics` (peel-by-id, `RD2205`, Contributor/Appendix landings, reserved Overview child, equal sibling indent, cookbook). Research: [directory-plus-index semantics](/research/rocdown/docs-directory-semantics.md). Exploratory; do not log complete until CI and Knowledge succeed.
* [Name Rocdown page and nav view types](named-roc-view-types.md) - Stable Roc aliases for `PageView` / `NavGroupView`, annotate `RocdownBuild`, ascribe generated `pages`. Research: [anonymous page-view records](/research/rocdown/named-roc-view-types.md). Exploratory; no phase started.
