# Plans

* [Multiplayer falling-block demonstrator on rocci.dev](multiplayer-falling-block-demonstrator.md) - One same-origin public arena for up to eight active players and a measured target of fifty spectators. Browser code owns responsive falling-piece motion; Roc validates lock commits and owns boards, rotating one-target garbage, rounds, leases, and compact recovery snapshots. Exploratory; Phases 0–1 implemented on `multiplayer-falling-block-demonstrator`.
* [Comprehensive Rocci documentation for rocci.dev](comprehensive-rocci-documentation.md) - Rocci-first, Rocdown-authored manual spanning first contact, beginner curricula, task guides, concepts, exhaustive language/runtime/CLI/config reference, troubleshooting, accessibility, and governance. Uses the landed `rocci-docs` catalog, colocated app prose, attached declaration docs, and generated source trees as the single `/examples/` system. Rocdown product documentation is out of scope. Exploratory; Phases 0–6 implemented on `comprehensive-rocci-documentation`. Phase 7 ships the query set and first-use protocol; live newcomer sessions are a maintainer gate and are not invented in git.
* [Documentation generator for Rocci applications](rocci-app-docs.md) - Own app-docs staging in `crates/rocci-docs` (`rocci-docs` binary). Colocated Rocdown plus a full highlighted source tree mounts on rocci.dev at `/examples/<id>/`; only catalog `live` apps get separate hostnames. Skip Rocdown examples. Published source follows `@view` / `@patch` / `@command` / `@live`. Exploratory; Phases 0–6 implemented on `rocci-app-docs`, not CI-complete. Live hostnames remain planned until a staging deploy has served them. Follows [semantic handlers](action-handler-syntax.md).
* [Semantic view, patch, command, and live handlers](action-handler-syntax.md) - Replace `@on` with `@view`, `@patch`, and `@command` beside `@live`; mutations default to POST, commands return Roc data, and generated dispatch preserves Datastar 204 versus ordinary-client JSON. No compatibility aliases or raw JSON-text result path; all existing code converts in one cutover. Includes a complete handler-matrix example and real Roc build gates. Exploratory; no phase started. Research: [semantic handler syntax](../research/action-handler-syntax.md). Follow-on: [Rocci app docs](rocci-app-docs.md).
* [Python and uv operator pipeline](python-uv-ops-pipeline.md) - Replace CI, deploy, origin, and local maintainer shell with `tools/rocci-ops`. POSIX remains for container PID 1, `install-roc.sh`, and OpenSSH ProxyCommand. Exploratory; Phases 1–6 implemented in this revision; not CI-complete. Research: [Python uv findings](../research/python-uv-ops-pipeline.md).
* [Generated CQRS streams and JSON command responses](datastar-cqrs-action-responses.md) - Opt-in `@live` so Rocci generates `/sse` and `data-init`; `json` POSTs return 204 vs JSON. Keep the first-app counter one-shot; add `live-counter`; convert the hybrid island. Exploratory; Phases 1–5 implemented on `datastar-cqrs-action-responses`, not CI-complete. Research: [Datastar SSE vs fan-out](../research/datastar-cqrs-action-responses.md).
* [Ungrammar AST codegen for Rocci and Rocdown](ungram-ast.md) - Phased owned-struct generation from per-language ungrams via a shared `rocci-ungram` CLI; scanners and parsers stay hand-written. Exploratory; Phases 1–5 implemented on `ungram-ast-implementation`, not CI-complete.
* [Ungram follow-on backends after owned-struct codegen](ungram-follow-ons.md) - Freeze inspect tags and generate exhaustive `format_ast` walkers, add `NodeKind` highlighter coverage, generate `MdNode` from a Markdown ungram, and emit a public tree appendix. Do not generate `SyntaxKind`, highlighters, or a CST. Exploratory; no phase started.
* [OKF preview compile and render cost](okf-compile-render-cost.md) - After load-performance work, stop baking page HTML into the Roc renderer hash, write Rocci chrome from apply, and reuse the applicator across watch ticks. Exploratory; Phases 1–3 and 6 in this tree; Phases 4–5 skipped; not CI-complete. Follow-on: [deferred compile/render follow-ons](okf-compile-render-follow-ons.md).
* [Deferred OKF compile and render follow-ons](okf-compile-render-follow-ons.md) - Future work for the first three compile/render non-goals: keep embedded page Roc in the hash, skip-roc as an explicit host not the default, wasm apply-to-disk without embedding `roc`. Exploratory; no phase started.
* [OKF load-performance improvements](okf-load-performance.md) - Phased reduction of `okf::load` latency: split load spans, batch git provenance, preview-without-provenance, watch parse cache. Phases 1–4 implemented; Phase 5 skipped after a sub-second release remeasure.
* [Efficient publishing workflow for pre-built Rocdown sites and Rocci apps](efficient-publishing.md) - Build once on a toolchain host; local Docker serves artifacts. Keep `rocdown build --host native|wasm`. Phases 1–5 implemented on this branch (static Caddy, package/serve, musl `--target`, slim hybrid and app images). Phase 6 is a no-go: musl remains the portable process story; Wasm remains apply. Research: [efficient publishing](../research/efficient-publishing.md). Exploratory; not CI-complete.
* [Hybrid island hosting follow-ons](hybrid-island-hosting-follow-ons.md) - After the local Docker same-origin demo: WebKit-free `--no-window` binaries, a precompiled island binary without `roc` at runtime, and cross-origin CORS plus cookies. Static-first artifact Docker is [efficient publishing](efficient-publishing.md). Exploratory; no phase started.
