# Rocci knowledge

* [Architecture](architecture/) - Current system contracts and boundaries.
* [Decisions](decisions/) - Implemented and approved choices with their consequences.
* [Status](status/) - Dated implementation state and known limitations.
* [Plans](plans/) - Active and migrated implementation plans, including the proposed language-server plan.
* [Research](research/) - Reserved for non-normative evidence and synthesis.
* [Audits](audits/) - Reserved for findings against current behavior.
* [Case studies](case-studies/) - Reserved for concrete boundary examples.
* [Reference](reference/) - Migration and lookup material.
* [Design](design/) - Current design-system evidence and DTCG-informed research, explicitly separated from implementation authority.

The [Phase 2 migration matrix](migration-matrix.tsv) accounts for every section heading in the nine reports and plans that were at the repository root during migration. Phase 6 dispositions are recorded in the [consolidation reference](reference/consolidation.md).
