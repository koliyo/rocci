evidence. They are not descriptions of shipped behavior unless a current
knowledge record, crate README, test, or implementation source confirms a claim.

Phase 6 of the [OKF plan](OKF_PLAN.md) first moved seven dated reports here.
A later public-repo sweep archived remaining root plans and the `reports/`
tree so they are not the first files a GitHub visitor sees.
