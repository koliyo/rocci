# Support

Rocci is a maintainer-run experimental preview. There is no support SLA and no
promise of replies on a schedule.

## Where to look first

- Install and first run: [docs/install](https://rocci.dev/docs/install/) and
  the root [README.md](README.md)
- Language and stack: [Docs](https://rocci.dev/docs/)
- Short answers: [FAQ](https://rocci.dev/faq/)
- What is shipped vs deliberate limits: [Project status](https://rocci.dev/project/status/)
- Local build and current PR policy: [CONTRIBUTING.md](CONTRIBUTING.md)
  (pull requests are not accepted in this preview)

## Asking for help

Open a GitHub issue with the **docs** template when the public pages are
wrong or missing. Use the **bug** template for a reproducible failure.

Do not use GitHub issues for security reports. See [SECURITY.md](SECURITY.md).

Mail **oss@rocci.dev** only when the docs and issue tracker cannot carry the
question (for example, a private install blocker).
